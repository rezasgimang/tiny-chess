# tiny-chess-01

4 KB Python chess engine for [make.fun tiny-chess-01](https://make.fun/bounty/tiny-chess-01).

Negamax alpha-beta, iterative deepening (node budget), quiescence (captures+promotions), MVV-LVA and killers, transposition table, piece-square tables, check extension, repetition, null-move pruning. Stdlib only; lzma+base85 packed `main.py` ≤4096 bytes. MIT.
